# 天天向上 v0.1.0：第一版功能基线

日期：2026-10-31

## 已实现

- Android 原生应用及完整的第一版可点击界面。
- 跑步节拍器可手动开始、暂停、继续和结束；支持 160–220 BPM、每次增减 5 BPM 及输入整数频率。
- 节拍器用提示音逐拍引导，不作逐拍语音播报。提示音使用媒体音频通道，可与音乐或有声内容同时播放；可在应用内单独调节节拍音量，但仍受手机媒体音量上限约束。
- 前台服务和持续通知支持切到后台或锁屏后继续运行，通知可暂停、继续及结束。真实节拍记录保存在本机，可查看、重命名、删除和导出 JSON。
- 每周课表、力量训练指导、AI 语音教练、训练报告和设备连接均有明确标注的交互演示界面；演示数据与真实节拍记录隔离。

## 验证

- `:app:testDebugUnitTest :app:assembleDebug` 构建和单元测试通过。
- 已在用户的 Redmi K80 Pro 上安装并实听：修复媒体音频通道后节拍连续且节奏正常；采用更醒目的 60 毫秒提示音后，用户确认与背景音乐同时播放时声音足够明显。

## 范围边界

- 定时事件语音播报、真实课程执行、实时 AI 通话、训练效果分析及手表等测量设备接入尚未实现。
- 真实来电后的恢复、长时间锁屏运行、不同耳机和手机省电策略尚未完成真机验收。
- 此版本为可安装调试的功能基线，未提供正式发布签名包。
