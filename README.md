# 天天向上（daydayup）

运动中的节奏与语音指导工具。**第一版是 Android 应用**：跑步节拍器为真实可用功能，每周课表、力量训练指导、AI 语音教练、训练报告、设备连接为清晰标注"演示模式"的可点击流程。

> 演示数据不与真实记录混用；节拍次数不会被推算成步数、距离或运动成绩。

## 第一版范围

| 模块 | 第一版 | 后续 |
| --- | --- | --- |
| 跑步节拍器 | ✅ 真实可用（160–220 步/分、±5 调节、后台/锁屏持续、持续通知、记录与中断恢复） | 结合真实运动数据 |
| 每周课表 | 🔵 演示 | 持久化课表与执行 |

| 设备连接 | 🔵 演示 | 手表等设备接入 |

## 当前实现

本仓库已包含 Kotlin + Jetpack Compose Android 工程。实际构建使用 Gradle 8.11.1、AGP 8.9.2、Kotlin 2.1.20、Android SDK 35。`docs/tech-stack-v1.md` 是更复杂技术栈的早期选型分析，**不是当前代码的依赖清单**。

- 真实节拍器使用 `mediaPlayback` 前台服务、短 PCM 提示音、持续通知和本地 JSON 记录；节拍器没有语音播报。
- 课程、力量训练、AI 教练、报告和设备连接是 Compose 可点击演示，不连接云端或测量设备。
- 演示数据与真实记录分开；真实记录支持查看、重命名、删除和 JSON 导出。

## 构建与运行

使用 Android Studio 打开仓库根目录，并配置 JDK 17 与 Android SDK 35。Windows 命令行：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
首次使用 Gradle Wrapper 需要联网下载 Gradle 8.11.1；已有同版本 Gradle 的环境也可直接运行其 `gradle` 命令。

## 验证边界

模拟器已用于验证应用启动、前台服务、切到后台后服务继续运行，以及真实记录写入。模拟器没有验证实际可听音质、与音乐/微信读书同时播放、真实来电和不同品牌手机的省电策略；这些需要目标真机检查。
